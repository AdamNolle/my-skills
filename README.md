### Design UI

An interface-design skill grounded in a study of 22 thoughtful digital experiences. It helps shape the important decisions first—purpose, art direction, composition, typography, surfaces, assets, responsive behavior, and interaction—then carries that intent through implementation and review.

**Use it for:** a new site, a product interface, a visual refinement, art direction, icon direction, or a reference-informed design critique.

**Invoke it with:** `$design-ui`
