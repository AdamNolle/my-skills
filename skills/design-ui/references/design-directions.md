# Choosing an art direction

These are ways to make decisions, not templates. Start with content and the user's goal. Every direction can be light or dark when its material and contrast system support the choice.

| Direction | Strongest references | Its central move | Best application |
|---|---|---|---|
| Calm physical product | Daylight, Electronic Materials Office, Apple | Make the object and its use feel tangible; reveal benefits in a deliberate sequence | Hardware, considered commerce, focused tools |
| Editorial studio | Studio Loop, Locomotive, Zhenlong, Adoratorio, Victor, Filmbot | Make typography and an authored grid carry the identity | Studios, cultural products, portfolios, service brands |
| Photographic instrument | Remy, Nick Ho, Lando | Give imagery a strong frame and use compact metadata as a navigation language | Photography, film, sport, image collections |
| Immersive collection | Immersive Garden, Active Theory, MONOGRID, Cartier, 60fps Watch | Let an object or environment organize the encounter | Campaigns, luxury, experiential portfolios, product demonstrations |
| Precision software | Raycast, Forge | Show a useful interface in an expressive but controlled setting | Software marketing and carefully adapted app UI |
| Tactile object system | Parakeet, Weird Folders, Leonardo | Use a coherent family of recognizable objects as the brand or navigation language | App identity, creative utilities, playful collections |

## Reference combinations that have a reason

**Studio portfolio:** Locomotive's editorial hierarchy + Loop's warm material palette. Use large project titles and offset media, then allow a small amount of collage in the brand introduction. Do not put a collage behind every project row.

**Photographer:** Remy's focused image selection + Locomotive's legible project archive. Keep a stable project identity while switching representations. Offer a straightforward route to work and contact. The photography should still win when effects are disabled.

**Hardware launch:** Daylight's contextual photography + Apple's benefit sequence. Begin with the desired human experience; follow with a controlled product study, useful details, and specifications. EMO supplies a darker alternative when the object's materials and audience support it.

**Desktop productivity app:** Raycast's focused command surface + Parakeet's coherent glyph family. Use detailed app identity at launch and in promotional assets; use simpler utility glyphs inside dense workflows.

**Creative file manager:** Weird Folders' material character + a conventional list/detail workflow. Rich folder art can aid recognition. Search, selection, sorting, rename, progress, and recovery still need unmistakable controls.

**Luxury campaign:** Cartier's material lighting + Immersive Garden's atmosphere. Keep commerce reachable and give the viewer an accessible list of items. The environment should make the collection more understandable, not bury it.

## Translate a reference into a design mechanism

Use this sentence pattern internally:

“Because **[content / audience need]**, use **[compositional relationship]** from **[reference]**, expressed through **[original assets and tokens]**, with **[interaction consequence]**.”

Example: “Because the work is mostly portrait photography, use Remy's single active image surrounded by quieter alternatives, expressed through the photographer's own images and a warm charcoal interface, with a grid view that retains the selected project.”

An adjective such as premium, cinematic, beautiful, or playful is incomplete until it has a material consequence: lighting, crop, type width, page rhythm, sound policy, timing, density, or state behavior.

## A useful limit on visual novelty

Choose one dominant source of surprise per screen: a unusual composition, spectacular image, custom lettering, rich material, or spatial interaction. Supporting details should reinforce it. Several can coexist across a longer page if the sequence gives them room.

The chosen direction should answer:

1. What remains recognizable if the logo disappears?
2. What stays compelling in a still image?
3. What does motion explain that the still cannot?
4. Which parts become quieter after a visitor returns for the tenth time?
5. Which reference conventions would harm this product's task?

Do not impose a blanket ban on common fonts, gradients, cards, or rounded corners. Raycast's inspected page declares Inter and Forge declares Geist. Their distinction comes from composition, lighting, assets, and detail. Familiar primitives can be excellent when they have a reason.

## Selecting assets before effects

An immersive direction has a higher asset and engineering burden. If the brief lacks strong photography, product renders, or a meaningful spatial model, resolve that gap before choosing a 3D hero. A finely set editorial page with an excellent still image can express this user's taste more convincingly than a weak object floating in an expensive effect.

If assets are unavailable, choose a direction that works with the actual content or create the needed assets through appropriate tools. Do not silently replace an essential hero photograph with unrelated stock imagery, an abstract gradient, or improvised vector art.
